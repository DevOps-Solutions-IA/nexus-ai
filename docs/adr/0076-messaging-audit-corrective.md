# ADR-0076: Messaging Channels — independent-audit corrective

Status: Accepted. Corrects four functional gaps an independent audit found in the initial NXS-P09 delivery (ADR-0069..0075). This is a real runtime correction, not evidence-only.

**A — webhook timestamp / replay freshness.** The generic Email / SMS signed-webhook protocol now has deterministic timestamp semantics (`verify_generic_signed_webhook` in `nexus_ai.messaging.providers.base`): `X-Messaging-Timestamp` is MANDATORY and part of the HMAC-SHA256 over `"<unix_ts>." + body`. A missing signature or timestamp is an explicit `NXS_MSG_SIGNATURE_INVALID` (not "unsigned"); a malformed timestamp is `NXS_MSG_SIGNATURE_INVALID`; a body or timestamp tampered after signing fails the constant-time HMAC; a **correctly-signed** request whose timestamp is outside `± settings.channels.webhook_timestamp_tolerance_seconds` (default 300, bounded 30–3600) is `NXS_MSG_REPLAY_REJECTED`. WhatsApp's Meta `X-Hub-Signature-256` carries no timestamp protocol and is unchanged — the tolerance argument is accepted for a uniform interface and unused there.

**B — delivery-callback crash consistency.** The status-callback path is now ATOMIC. `InboundMessagingService._process_status` runs in ONE tenant transaction: claim the per-event receipt → resolve the target message → fold the monotonic transition → persist the state → link the receipt → enqueue the P04 event → COMMIT. Any failure rolls the receipt back with everything else, so a provider retry reprocesses safely. A callback for a message that is not yet visible is DEFERRED (no receipt committed) rather than swallowed. The old two-transaction `_claim_only()` + `MessagingService.apply_delivery_status()` split is removed. Concurrency dedupe is preserved by the receipt's `UNIQUE(organization_id, account_id, event_id)`.

**C — Email reply-thread governance.** `SendMessageRequest.reply_to_message_id` is now resolved and governed by `MessagingService._require_reply_parent`: the parent must exist in the authenticated Organization, belong to the SAME Conversation, and — for an Email reply — itself be an Email message; a cross-tenant, wrong-conversation or wrong-channel parent is `NXS_MSG_CONVERSATION_INVALID`. A composite tenant-aware self-reference foreign key `(organization_id, reply_to_message_id) → messaging_messages(organization_id, id)` (`ON DELETE SET NULL`, migration `c1d2e3f4a5b6`) makes a forged cross-tenant relation impossible at the database; a root message keeps `reply_to_message_id` NULL. `MessagingService._email_thread_fields` derives `In-Reply-To` and `References` from the parent, CRLF / control-character safe via `sanitize_header_value`; the `EmailProvider` now emits `Message-ID`, `In-Reply-To` and `References` headers. **`email.message_id_header` is the canonical threading identifier** for a Nexus message (generated on every outbound Email, copied from the provider id on every inbound Email); `provider_message_id` is the provider's opaque id and is not used for threading. An inbound Email Message-ID is scrubbed of control characters at ingest (`content.scrub_header_token`).

**D — bounded provider account configuration.** `nexus_ai.messaging.account_config.validate_account_configuration` replaces the raw `dict[str, Any]`: an allow-list per `(channel, provider)` (`graph_base` / `api_version` / `default_country` for WhatsApp; `api_base` / `default_country` for Email and SMS), plus bounds from typed settings — key count (≤ 12), key length (≤ 64), value length (≤ 512), nesting depth (≤ 3), serialised size (≤ 4096 bytes). `graph_base` / `api_base` must be a plain `https://` origin (no credentials, query or fragment) and still passes the NXS-P07 `DestinationPolicy` / `GovernedHttpExecutor` at send time. No per-send URL / method / header surface is introduced — `SendMessageRequest` is unchanged and still exposes none.

Consequences: the signed webhook edge is replay-proof; a partial delivery-callback failure cannot silently drop a lifecycle event; email threading is a real, governed, database-enforced relation; a channel account cannot be a smuggling vector for transport configuration.
