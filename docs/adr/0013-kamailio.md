# ADR-0013: Kamailio SIP edge

Status: Accepted historical P00 architectural reservation. Kamailio was reserved
as the signaling edge ahead of Asterisk Cells; this was not an implementation.
ADR-0100 and the P19 engineering design now refine that reservation into the
authoritative SIP Edge Scaling governance contract. P19 remains PLANNED/PENDING;
no Kamailio runtime configuration, deployment or capacity certification exists yet.
P11 telephony and P18 placement are implemented independently of this reservation.
