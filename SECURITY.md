# Security Policy

Report suspected vulnerabilities privately through GitHub Security Advisories for `DevOps-Solutions-IA/nexus-ai`; do not include secrets, customer data, or exploit material in public issues. If private reporting is unavailable, contact the repository owner through an established private organizational channel.

Critical findings fail immediately. High findings fail unless a named owner, expiry, compensating controls, and approval are recorded as a time-bounded risk acceptance. Medium findings require review and disposition. Secrets must never enter commits, logs, evidence, images, or AI prompts; suspected exposure stops closure and requires removal and rotation.
